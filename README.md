# Pseudocode Assessment – Section B

This repository contains structured pseudocode answers and trace tables for the five Section B problems.

## Files
1. `Question_1_BranchOffice.md` – Static data members, static functions and encapsulation
2. `Question_2_Matrix2D.md` – Arrays in a class, scope resolution and friend function
3. `Question_3_StudentRecord.md` – Array of objects and Bubble Sort
4. `Question_4_Logger.md` – Function overloading, default arguments and inline helper
5. `Question_5_RegisterBank.md` – Return by reference and lvalue assignment

**Note:** Sample values are stated wherever the question does not provide transaction or student data. The pseudocode is language-neutral, with C++-style scope-resolution and reference notation where required.
